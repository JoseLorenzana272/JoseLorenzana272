## 🛡️ What I'm building

<table>
<tr>
<td width="55%">

### [Fortress in a Box](https://fortressinabox.dev)

Enterprise-grade Kubernetes security, deployed in a single command. Built for **NGOs, journalists, and human rights organizations** — the people who get targeted the most and have $0 security budgets.

**The reality:** Organizations like Red Cross, Amnesty International, and investigative journalists are constantly attacked by state-sponsored actors. The asymmetry is deliberate. Fortress in a Box closes that gap.

```bash
git clone github.com/JoseLorenzana272/fortress-in-a-box
./install.sh
# ╔══════════════════════════╗
# ║  FORTRESS IS ACTIVE :D  ║
# ╚══════════════════════════╝
```

</td>
<td width="45%" align="center">

**4-layer defense model**

| Layer | Tool | What it does |
|-------|------|-------------|
| CI/CD | Trivy | CVE scanning before deploy |
| Admission | Kyverno | 6 policies, zero exceptions |
| Runtime | Falco | Shell access → instant alert |
| Recovery | ArgoCD | Git drift → auto-restored |
